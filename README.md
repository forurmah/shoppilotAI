# ShopPilot AI

A full-stack clothing e-commerce application with an AI-powered shopping assistant, built with React and TypeScript.

## Problem
Customers frequently ask about prices, product availability, and clothing options. ShopPilot AI aims to make reliable product information easier to access and help store administrators manage their catalog.

## Current progress
- [x] Vite + React + TypeScript setup
- [x] Initial navigation and header
- [x] Hero section
- [ ] Product data modeling in TypeScript
- [ ] Product catalog
- [ ] Shopping cart
- [ ] Backend and database
- [ ] AI shopping assistant

## Tech stack
React, TypeScript, Vite, pnpm, CSS.

## Run locally
```bash
pnpm install
pnpm dev
```

## Development approach
Built incrementally over a 90-day learning and engineering roadmap. Each feature is implemented, tested, and documented as the project grows.
